# coding-pipeline

## What Council does with it

- Route well-scoped, mechanical maintenance work to a cheap, fast executor.
- Keep contested design, cross-cutting refactors and ambiguous requirements with the strongest executor or a human.
- State the acceptance check up front so any executor can be verified the same way.

See ../../CONSTITUTION.md for the rules every run follows.
