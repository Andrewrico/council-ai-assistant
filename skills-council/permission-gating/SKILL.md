# permission-gating

## What Council does with it

- Every execution recommendation names its minimum toolset and an explicit deny list.
- Scope permissions by path or glob where the executor supports it.
- Call out when an executor's default permissions are broader than the proposal.

See ../../CONSTITUTION.md for the rules every run follows.
