# grounded-research

## What Council does with it

- Every factual claim in a research result links to a source; unsourced claims are labeled as such.
- Prefer an executor with real web search and long context for broad research.
- Never send web research to an executor that has no web-fetch tool.

See ../../CONSTITUTION.md for the rules every run follows.
