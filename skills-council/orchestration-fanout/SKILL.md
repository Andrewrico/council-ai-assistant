# orchestration-fanout

## What Council does with it

- Gather 3+ independent perspectives (subagents, other tools, or separate passes) before a contested call.
- State the level of agreement and any dissent explicitly; never average away a minority warning.
- Hand the actual work to the best-suited executor; fan-out informs the choice, it does not replace it.

See ../../CONSTITUTION.md for the rules every run follows.
