# channel-acp-interop

## What Council does with it

- For multi-channel or chat-surface work, recommend a channel-agnostic gateway rather than per-surface code.
- To drive another coding harness, consider the Agent Client Protocol (agentclientprotocol.com) instead of ad-hoc scripting.
- Name the trade-off (setup cost versus reuse) when recommending a bridge.
